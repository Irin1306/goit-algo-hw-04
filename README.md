 # Висновки

Insertion Sort:
- ефективний для малих або майже відсортованих масивів
- погано масштабується через квадратичну складність O(n²)

Merge Sort:
- стабільна продуктивність O(n log n) незалежно від структури даних
- відсутність оптимізацій під частково відсортовані дані 

Timsort (sorted):
- поєднує переваги insertion sort(для малих підмасивів) і merge sort(для великих) 
- адаптується до частково відсортованих даних
- оптимізований на рівні реалізації Python

  
| Algorithm        | Small random data  | Small sorted data  | Big random data    | Big sorted data   
| ---------------- | ------------------ | ------------------ | ------------------ | ------------------
| Insertion Sort   | 0.000326           | 0.000034           | 0.149225           | 0.000723          
| Merge Sort       | 0.000473           | 0.000414           | 0.021972           | 0.011074          
| Timsort          | 0.000019           | 0.000010           | 0.000860           | 0.000081 

Bбудований алгоритм Python Timsort є оптимальним вибором, оскільки поєднує надійність і швидкодію завдяки адаптивності до структури даних
